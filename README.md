# Farshad Naderi — Personal Website

A minimal, responsive personal website built with Next.js and TypeScript.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm start
```

## Deployment

The project is ready to deploy on Vercel. Import this GitHub repository and use the default Next.js settings.
